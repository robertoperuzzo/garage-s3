Welcome to the Garage S3 documentation for your homelab deployment.

Use the **Single Node Setup** page to walk through configuring the provided Docker Compose stack, running the node, and upgrading later. The repository already includes `docker-compose.yml` alongside `garage.example.toml`, so you can copy the example configuration and plug in your own tokens and paths.

To preview the docs locally (optional):

```bash
pip install mkdocs
mkdocs serve
```

Navigate to `http://127.0.0.1:8000` once the server is running.
